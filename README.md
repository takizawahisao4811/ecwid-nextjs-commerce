# Next.js E-commerce for Selling Drone

A Next.js e-commerce storefront for selling drones, built with React and modern web technologies.

## Features

- Product listing
- Shopping cart
- Checkout flow
- Responsive design

## Getting Started

1. Install dependencies

   ```sh
   npm install
   ```

2. Run the development server

   ```sh
   npm run dev
   ```
